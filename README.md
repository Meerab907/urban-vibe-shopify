Urban Vibe Co. Shopify Store
 Project Overview
Urban Vibe Co. is a Shopify store designed to sell affordable and stylish lifestyle accessories like caps, wallets, and sunglasses, targeting university students and young adults. The store emphasizes a modern, clean, and mobile-friendly design with easy navigation and a secure checkout system.
Note: The Shopify store is currently not live. The public URL will be shared once deployed.
